# Perspectiva Matemática

> Quantitative dashboards and market analysis from a mathematical perspective.

**Perspectiva Matemática** is a public research hub focused on quantitative
market analysis, interactive dashboards and data-driven financial
visualization. The site gathers projects built around financial time series,
market events, commodities, sectors and market-based sentiment indicators.

**Live site:** https://perspectivamatematica.github.io/

---

## Projects

- **Event Window** — Event-based analysis of how financial assets behave
  before and after relevant market events, geopolitical shocks and
  commodity-related episodes.
- **Silver Dashboard** — Commodity dashboard focused on silver market
  dynamics, related assets, macro drivers and statistical signals.
- **Sectors** — Sector behavior, relative performance and market rotation
  across different phases of the investment cycle.
- **Sentiment** — Market-based sentiment indicators that transform financial
  variables into interpretable measures of risk appetite and stress.

Each project links to its interactive dashboard (Streamlit) and to its own
source code repository.

---

## Stack

Static site built with HTML, CSS and JavaScript. No build step, no backend.
Hosted on GitHub Pages. The interactive dashboards are deployed separately
on Streamlit.
